# FitMatch (frontend)

Frontend navegável, mobile first, de uma plataforma onde cozinheiros de comida fitness postam e vendem e clientes descobrem, seguem e pedem. Usa apenas dados de exemplo (mock), sem backend.

**Stack:** React 18 + TypeScript + Vite + React Router.

## Comandos

```bash
npm install
npm run dev        # servidor de desenvolvimento
npm run build      # typecheck + build de produção
npm run lint       # ESLint
npm run format     # Prettier
```

## Estrutura

```
src/
  components/  componentes reutilizáveis
  pages/       telas (rotas)
  data/        dados de exemplo (mock)
  types/       tipos TypeScript
  hooks/       hooks customizados
  utils/       funções utilitárias
  styles/      estilos globais
```
